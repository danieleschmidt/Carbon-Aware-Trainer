## 2. Related Work

### 2.1 Carbon-Aware Computing

Early work in carbon-aware computing focused on temporal shifting of batch workloads based on historical carbon intensity data [1,2]. Strubell et al. [3] first quantified the carbon footprint of neural architecture search, highlighting the environmental impact of large-scale ML training. Recent efforts have explored geographical load balancing [4,5] and carbon-aware scheduling [6,7].

However, these approaches suffer from three limitations: (1) reliance on historical rather than predictive data, (2) classical optimization methods that do not scale to complex multi-objective problems, and (3) lack of real-time adaptation capabilities.

### 2.2 Quantum Machine Learning

Quantum machine learning has shown theoretical advantages for specific problems [8,9], with recent demonstrations of quantum advantage in optimization [10,11] and machine learning [12,13]. Variational quantum algorithms have proven particularly promising for near-term quantum devices [14,15].

Despite theoretical progress, practical quantum advantage in real-world applications remains elusive. Previous work has not demonstrated quantum speedup for carbon optimization or sustainability applications.

### 2.3 Sustainable AI Systems

The field of sustainable AI has emerged to address the environmental impact of machine learning [16,17]. Green AI principles [18] advocate for efficiency-first design, while recent work explores hardware-software co-design for energy efficiency [19,20].

Our work builds upon these foundations while introducing quantum enhancement, real-time adaptation, and autonomous discovery capabilities not present in existing systems.

#### A.2 Quantum Machine Learning Kernel

Our quantum kernel implementation uses feature maps to encode classical data:

```python
def quantum_feature_map(x):
    """Quantum feature map for carbon data"""
    qc = QuantumCircuit(num_qubits)
    for i, feature in enumerate(x[:num_qubits]):
        qc.ry(feature * np.pi, i)
        qc.rz(feature * 2 * np.pi, i)
    
    # Entangling gates
    for i in range(num_qubits - 1):
        qc.cnot(i, i + 1)
    
    return qc

def quantum_kernel_matrix(X_train, X_test):
    """Compute quantum kernel matrix"""
    kernel = QuantumKernel(quantum_feature_map, quantum_backend)
    return kernel.evaluate(X_train, X_test)
```

### Appendix B: Statistical Analysis Details

#### B.1 Hypothesis Testing Procedures

All statistical tests follow rigorous protocols:

```python
def statistical_significance_test(control_group, treatment_group, alpha=0.05):
    """Perform Welch's t-test with effect size calculation"""
    t_stat, p_value = stats.ttest_ind(treatment_group, control_group, 
                                     equal_var=False)
    
    # Cohen's d effect size
    pooled_std = np.sqrt((np.var(control_group, ddof=1) + 
                         np.var(treatment_group, ddof=1)) / 2)
    cohens_d = (np.mean(treatment_group) - np.mean(control_group)) / pooled_std
    
    return {
        't_statistic': t_stat,
        'p_value': p_value,
        'significant': p_value < alpha,
        'effect_size': cohens_d,
        'power': calculate_power(cohens_d, len(control_group), len(treatment_group))
    }
```

#### B.2 Multiple Comparisons Correction

When testing multiple hypotheses, we apply Bonferroni correction:

```python
def bonferroni_correction(p_values, alpha=0.05):
    """Apply Bonferroni correction for multiple comparisons"""
    corrected_alpha = alpha / len(p_values)
    significant = [p < corrected_alpha for p in p_values]
    return significant, corrected_alpha
```

#### C.2 Federated Learning Security

```python
class SecureFederatedLearning:
    def __init__(self, privacy_budget=10.0):
        self.privacy_budget = privacy_budget
        self.differential_privacy = DifferentialPrivacy(privacy_budget)
        self.homomorphic_encryption = HomomorphicEncryption()
    
    async def secure_aggregation(self, client_updates):
        """Perform secure aggregation with privacy preservation"""
        # Add differential privacy noise
        noisy_updates = [
            self.differential_privacy.add_noise(update) 
            for update in client_updates
        ]
        
        # Homomorphic encryption for secure computation
        encrypted_updates = [
            self.homomorphic_encryption.encrypt(update)
            for update in noisy_updates
        ]
        
        # Secure aggregation
        aggregated_encrypted = self.homomorphic_encryption.aggregate(encrypted_updates)
        aggregated_result = self.homomorphic_encryption.decrypt(aggregated_encrypted)
        
        return aggregated_result
```
